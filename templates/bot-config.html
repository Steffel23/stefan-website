Discord Bot Commands

Maximale Server-Effizienz mit einem Klick kopieren

🛡️ Moderation & Server-Schutz (Dyno / MEE6)
?ban @User [Grund] Bannt einen störenden Nutzer permanent vom Discord-Server.
?timeout @User 10m [Grund] Versetzt einen Nutzer für 10 Minuten in den Server-Timeout.
?purge 100 Löscht blitzschnell die letzten 100 Nachrichten im aktuellen Kanal.
?lock Sperrt den aktuellen Kanal sofort für alle normalen User (Raid-Schutz).
?warn @User [Grund] Erteilt einem Mitglied eine offizielle Verwarnung im System.
🎫 Support-Ticket-System (Ticket Tool)
$setup Startet das interaktive Setup für ein Ticket-Panel im Kanal.
$close Schließt ein geöffnetes Support-Ticket nach der Bearbeitung.
$add @User Fügt ein weiteres Team-Mitglied oder einen User zum Ticket hinzu.
$claim Übernimmt das Ticket als Supporter, um es alleine zu bearbeiten.
