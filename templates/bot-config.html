Discord Bot Commands

Kopiere die nützlichsten Befehle für deinen Server mit einem Klick!

🛡️ Moderation & Server-Schutz (Dyno / MEE6)

?ban @User [Grund]
Bannt einen störenden Nutzer permanent vom Discord-Server.
?timeout @User 10m [Grund]
Versetzt einen Nutzer für 10 Minuten in den Server-Timeout (Stummschaltung).
?purge 100
Löscht blitzschnell die letzten 100 Nachrichten im aktuellen Textkanal.
?lock
Sperrt den aktuellen Kanal sofort für alle normalen User (Raid-Schutz).

🎫 Support-Ticket-System (Ticket Tool)

$setup
Startet das interaktive Setup für ein Ticket-Panel im Kanal.
$close
Schließt ein geöffnetes Support-Ticket nach der Bearbeitung.
$add @User
Fügt ein weiteres Team-Mitglied oder einen User zum Ticket hinzu.

🎮 Utilities & Level-System (MEE6)

!rank
Zeigt deine aktuelle Level-Karte und gesammelte XP auf dem Server an.
!levels
Gibt den Link zur kompletten Server-Rangliste aus.
!user-info @User
Zeigt wichtige Account-Details wie Beitrittsdatum und Rollen eines Nutzers.
